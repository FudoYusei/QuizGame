UIScreens  
-----------------
本项目中, 所有需要用到的 UI 界面都集中在 UIScreens 中  
UIScreens 中包含所有需要使用的页面, 在不同场景上显示隐藏不同的页面  

UIManager  
--------------
UIManager 是整个 UI 的管理者, 它负责整个 UI 层的生命周期. UIManager 管理通用的 UI 界面, 例如 起始界面, 设置界面等.  
如果是复杂场景中自带的复杂UI, 也可以直接在场景中创建类似的 UIManager/UIController/UIPresenter   

UIManager 的主要功能:  
1. 实例化 UIManager 管理的页面
   1. 初始化 UI Document, 只需要在 UIManager 所在的 GameObject 上附加 UIDocument 组件, 然后引用对应的 UI Asset 即可, 会跟随 GameObject 在场景中一同实例化  
   2. 接下来, UIManager 需要初始化 Screen 对应的脚本实例(UIScreen), 并且将UIDocument的RootElement传递给脚本, 实现两者绑定  
   3. 如果页面比较复杂, 做了显示逻辑和业务逻辑分离, 还需要实例化 Presenter/Controller, 并且绑定Screen和Presenter/Controller实例
2. 订阅外部事件, UIMananger 负责页面的显示和隐藏逻辑, 所以订阅的外部事件基本都是显示/隐藏某个页面
3. 页面之间的回退功能, 因此需要维护一个页面栈
