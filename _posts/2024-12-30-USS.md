USS 规则  
--------------
USS 规则基本和网页开发的 CSS 一致  

USS 调试 
-------------
Unity 自带了 UI Toolkit Debugger, 通过点击 Pick Element 按钮, 选择想要查看的 UI Element, 即可查看运行时, Element 的实际样式  


USS 常见问题一 不生效
----------------
USS 常见问题就是, 为页面定义的 USS 不生效.  
1. 确认 USS 中未生效的属性
2. 确认该属性在 UI Element 中是否被设置为 inline style  
3. 确认该属性是否被后置位的 USS 覆盖

USS 常见问题二 inline style  
-------------------
直接在 UI Element 本体上设置某个属性, 这个属性被称为 inline style, 也就是常见的内敛样式. 这种样式的优先级最高, USS 无法覆盖.  
我们可以在 UIBuilder 的 inspector 中修改 inline style, 一旦某个属性被修改, 在 Inspector 中该属性的左侧会有一个明显的白条.  

我们可以在属性上点击右键->unset, 来直接取消这个 inline style  

> ##### TIP
>
> 在 Inspector 中右键->unset all, 表示取消当前 Inspector 中所有的 inline style, 慎用
> 对于一些具有多个子属性的属性A, 点击属性名称A->unset, 会取消所有子属性
> 点击单个子属性名称->unset, 会单独取消这个子属性. 同时有个不易察觉的视觉效果, 具有 inline style 的子属性本身是加粗的
{: .block-tip }

USS 动画
-----------------
USS 无法像 UGUI 那样做丰富的动画. 但是可以通过 transition 属性来实现一些简单的动画  
在 USS 中修改 transition 的值, 表示当前 USS 中的属性全部会应用 transition 来进行转换. 例如, 当 transition 的 duration 设置为 1s. 即表示, 一旦某个元素应用了这个 USS, 那么这个元素上的属性会在 1s 的持续时间内通过转换函数将值转换为 USS 中的值  

以 screen-hidden 举例, screen-hidden 是一个控制 fade out 的样式, 具体表现形式是, 在 duration 时间内, 向下移动出屏幕, 同时透明度变为 0  

> ##### TIP
>
> Position属性下的Offset属性虽然可以实现 translation 动画, 但是一般情况下, Position 属性用于进行初始化布局, 很多直接使用 auto 值, 而 auto 值无法进行动画, 它会计算所有样式得出最终结果
> 如果想要 translation 动画, 需要修改 Transform 下的属性, 就和 Unity Object 的 Transform 组件一样
> 修改 Translate 属性中的 Y 为 100%, 表示 Element 会从当前位置向下移动出屏幕外, 为了预览动画效果, 点击 Viewport 中的 Preview, 并且在 Inpsector 中的 styleclasslist 中添加 .screen-hidden
{: .block-tip }  

<font color=#e84118>最好不要拖拽样式到元素上, 很容易把样式拖拽到别的 USS 文件中, 直接在 Inspector 中添加</font>  

USS transition 属性
-----------------
transition 属性同样适用于 USS 的属性控制优先级.  
也就是说, 一旦我们在 UI Elements 中设置了 transition 的值, 它也变成了一个 inline style, 我们可以单独设置一个 screen-transition 样式来控制是否进行动画效果  

例如, 一个动态样式 screen-transition 中设置了 transition 的值, 并且将它置于 UI Element 上, 之后给 UI Element 添加不同的样式, 所有的属性都会应用 transition 的效果. 观察 inspector, UI Element 的 transition 使用的就是 screen-transition 的值  

不同的动画效果 USS, 可以单独设置自己的 transition 值, 新添加的 USS 会使用自身的 tansition 值覆盖到 Element 中, 因此, 不需要担心, 后设置的 USS 都是可以使用自身的 transition 信息  

但是, 也需要注意, 如果有一个动画样式被设置了, 那么后续添加的样式都会受到这个动画样式的 transition 值的影响, 被感染称动画样式.
