FlexBox
-----------------
使用一些 DEMO 来解释 UI Toolkit 内置的组件运行机制  

自适应布局和响应式布局 
--------------------  
[详细说明](https://zhuanlan.zhihu.com/p/347322236)  
自适应布局指的是, 通过查询设备的特性和屏幕尺寸, 设定不同的布局规则来适应不同的设备.  
响应式布局指的是, 检测视口分辨率, 设置不同尺寸下的元素比例.  

游戏UI  
--------------
游戏中的 UI 通常不像网页端, 比例变化大, 从横屏变化等到竖屏. 游戏 UI 基本直接设计为横屏或者竖屏其中之一.  
通常来讲, 3D游戏中, 菜单只会等比例缩放  

flex-basis
-------------
flex-basis 就是 flex-box 缩放的基础, 缩放的基础为布局的基础, flex-box 布局自适应会根据 basis 进行计算.  
shrink 和 Grow 参数会控制缩放. 如果容器为固定的分辨率, 那么 flex-box 会根据 basis 设置的分辨率进行缩放.  

#### 固定大小与可变大小
所有 UI 元素的 shrink 参数默认设置为 1. 本意是, 当屏幕大小无法显示子元素大小时, 对子元素进行缩放, 以保证子元素的内容能够最大限度的展示. 因此, 下面讨论的情况都是基于 shrink 设置为 1 的默认情况.  

如果设置某个 UI 元素的 basis 为百分比, 那么这个 UI 元素会随着整个容器的分辨率改变而改变, 可变大小的 UI.  
例如, 处于 Horizontal flow 中的 UI 元素, 设置 basis 50%, 那么随着父元素分辨率从 1000px 改变为 2000 px. UI 元素的宽度也会拉伸两倍, 有可能导致 UI 失真  

如果设置某个 UI 元素的 basis 为固定大小的 px, 那么这个 UI 元素会基于这个分辨率显示, 依然会受到 shrink 以及 grow 参数的影响.  
例如, 处于 Horizontal flow 中的 UI 元素, 设置 basis 500px, 当整个屏幕是1000px的时候, UI 元素依然保持 500 px, 但是当屏幕分辨率调整为 250px 的时候, UI 元素的宽度会被缩放为 250px  

不同分辨率如何保证合适的比例?  
这种缩放的极限情况应该是不用考虑的. 游戏中最多考虑一下 4:3 16:9 16:10 这种依然是宽屏比例的内容显示  


Spacing
-------------
Spacing 可以设置为 px 为单位的数值, 以及百分比数值.   

#### 百分比
https://segmentfault.com/a/1190000004231995  

当元素处于 horizontal flow 时, 设置 Margin-top 或者 Margin-Bottom 为百分比, 并不像我们认为的是根据父元素高度的百分比, 而是父元素宽度的百分比  

<font color=#4cd137>仔细思考是合理的, 首先区分 FlexBox 中的 Margin 和锚点系统中的 Margin</font>  
锚点系统中的 Margin 表示的是元素相对于父容器的距离  
FlexBox 中的 margin 是当前元素的 flexbox 的 margin  

<font color=#4cd137>Margin 设置为百分比就意味着当前元素的 Flexbox 是可变的, 这个可变指的是当前元素的长宽比例不变</font>  
设置为 px 的元素表示固定大小元素. 设置为百分比表示元素可以等比例缩放  

<font color=#4cd137>布局自适应指的是什么? 当分辨率发生变化的时候, 单个子元素的长宽比例不会失真</font>  

因为 FlexBox 根据父容器的设定, 在 Horizontal 和 Vertical 方向之一进行缩放
